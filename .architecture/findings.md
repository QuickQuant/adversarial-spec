### FIND-002: Top-level and standalone gauntlet CLIs use divergent timeout defaults

- **Category:** duplication
- **Severity:** warning
- **Confidence:** high
- **Component:** debate-engine / gauntlet
- **Files:**
  - `skills/adversarial-spec/scripts/debate.py:401-404`
  - `skills/adversarial-spec/scripts/gauntlet/cli.py:64-69`
  - `skills/adversarial-spec/scripts/gauntlet/orchestrator.py:205-224`
- **Observation:** The top-level debate parser defaults `--timeout` to 1200
  seconds; the standalone gauntlet parser defaults it to 1800 seconds. Both
  surfaces feed the gauntlet/model-call workflow, so the same operator intent
  can produce different deadline behavior depending on entry point.

  keep any intentional surface-specific override explicit in the component
  contract.
- **Evidence:** `debate.py:401-404` says 1200 seconds; `gauntlet/cli.py:64-69`
  says 1800; `run_gauntlet()` accepts the value at `orchestrator.py:205-224`.
